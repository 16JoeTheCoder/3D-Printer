# Decisions (v2 rebuild)

Where the instructions offered two ways, this is the choice made and why. Each one can be reversed.

1. **Palette: the spec's school blue, not the global ink/paper/fire tokens.** The global brand rule (ink #0D0E10, paper #F3F2EE, fire #FF5B1F) and the rebuild prompt (§8: paper #FAF8F4, brand #1F3A5F, accent #E4571E) disagree. The prompt is written for this project and its school audience, so it wins. Both systems agree that the orange is an accent only and never body text. To switch, change the `:root` tokens in `public/styles.css` and `DESIGN.md`.
2. **Fonts: `@fontsource-variable/fraunces` and `@fontsource-variable/inter`, with the WOFF2 files copied into `public/fonts/`.** The global rule says to use @fontsource and never a CDN. The prompt says no npm dependencies. Copying the files gets both: the fonts come from @fontsource, and the site has no runtime dependency and no `package.json`. Fraunces was reachable, so the Source Serif 4 fallback was not used.
3. **Branch: the session branch `claude/ecstatic-davinci-5w52hn` is committed and pushed, not left as uncommitted changes on `v2-rebuild`.** This session's environment requires the work to be pushed. Nothing is deployed: `npx wrangler deploy` was not run.
4. **`public/data/specs.json` holds display-ready rows, not a raw copy.** The prompt asks for a copy. Formatting each value once at build time means the compare page reuses exactly the strings the printer pages show, with no duplicated formatting code in `app.js`.
5. **`meta.siteUrl` is null.** The production domain is unknown, so canonical, Open Graph and sitemap URLs are root-relative and the build prints a note. Set `meta.siteUrl` (for example `https://<name>.<account>.workers.dev`) and rebuild to make them absolute. Sitemaps need absolute URLs to count.
6. **Model viewer on a dark brand panel.** The vendor viewer and its fallback SVGs are styled for a dark background. Putting the viewer on a `--brand` panel avoids editing the vendor files (`public/models/*`), which stay byte-identical to Josef's download.
7. **K2 Pro hotend.** The Docs list says "not confirmed"; `printer-specs.js` says 300 °C. The site shows "Not confirmed" (the Docs list wins). `scripts/check.mjs` reports this as a note rather than an error so the build still passes.
8. **Pinned carousel kept, with held positions.** Each slide holds still for about 16% of the scroll around its snap point, and the page uses `scroll-snap-type: y proximity`. A slide is fully visible at rest even when snapping does not engage. Mandatory snapping would trap the rest of the page.
9. **Speed shown as listed.** Creator 5 Pro shows "300 mm/s printing" (the 600 mm/s figure is travel only). The other printers show the maker's maximum, with real-use notes on their pages.
