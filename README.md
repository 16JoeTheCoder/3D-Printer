# STJBS printer shortlist
Static showcase of five 3D printers. `specs.json` is the single source of truth.
Build: `node scripts/render.mjs` writes `public/index.html` (committed).
Preview: `npx serve public` (or any static server); deploy with `npx wrangler deploy`.
Photos live in `assets/` (originals) and `public/img/` (webp); see `IMAGES.md`.
